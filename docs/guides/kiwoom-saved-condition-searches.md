# 키움 저장 조건검색식 목록

`kiwoom-demo`와 `kiwoom-real-vibe` 프로필에서 조회한 국내 조건검색식은 각각 30개이며, 일련번호와 이름이 동일하다. 두 목록 조회의 `return_code`는 모두 `0`이었다.

아래 설명은 **조건식 이름을 바탕으로 추정한 목적**이다. 목록 조회 응답에는 실제 지표 설정값, 기간, 비교 기준, AND/OR 조합이 포함되지 않는다. 이름이 같다는 사실만으로 두 프로필의 내부 조건까지 동일하다고 확인할 수는 없다. 정확한 규칙은 영웅문4의 `[0150] 조건검색`에서 해당 내 조건식을 열어 확인한다.
